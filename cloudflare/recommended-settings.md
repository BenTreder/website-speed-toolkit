# Recommended Cloudflare Settings

## Speed

```txt
Brotli: On
Auto Minify CSS: Optional
Auto Minify JS: Optional
Auto Minify HTML: Optional
Rocket Loader: Usually Off
```

## SSL

```txt
SSL Mode: Full or Full Strict
Always HTTPS: On
Automatic HTTPS Rewrites: On
```

## Test After Changes

- Clear cache
- Test mobile
- Test desktop
- Test forms
- Test checkout pages
