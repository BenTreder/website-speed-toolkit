# Website Speed Audit Checklist

## Images

- Compress hero images
- Use modern formats
- Add alt text
- Use lazy loading

## CSS

- Remove unused CSS
- Reduce large stylesheets

## JavaScript

- Remove unnecessary scripts
- Defer non-critical JS

## Caching

- Enable browser caching
- Configure Cloudflare caching

## Final Testing

- Test homepage
- Test mobile
- Test forms
- Run speed tests
- Clear cache
