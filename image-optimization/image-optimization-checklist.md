# Image Optimization Checklist

## Recommended Formats

```txt
Photos → WebP / AVIF / JPEG
Logos → SVG / PNG
Icons → SVG
Screenshots → WebP / PNG
```

## Recommended Sizes

```txt
Hero Images → 1600px or less
Blog Images → 1200px or less
Card Images → 800px or less
Thumbnails → 400px or less
```

## Checklist

- Compress images
- Use descriptive filenames
- Add alt text
- Avoid huge PNGs
- Lazy load lower images
